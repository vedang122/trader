# clint -> args, sdist-only packages whose legacy setup.py build dies against
# the Debian-patched setuptools in the cloud container
# ("AttributeError: install_layout"). pip fails the WHOLE file on one
# unbuildable dep, so a bare `growwapi` line silently left pandas, yfinance and
# pytest uninstalled too. Its runtime deps install cleanly, so they live here
# and the SDK itself goes in without its broken metadata:
#     pip install -r requirements.txt
#     pip install --no-deps growwapi
